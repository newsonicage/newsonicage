# ── Search engines ───────────────────────────────────────
# /discovery is repeated in EVERY block below, on purpose. A named block
# replaces the * block wholesale, so a Disallow that appears only under * does
# nothing for any agent named here — it would have blocked the anonymous
# crawlers and left the ones we actually name free to fetch.
#
# The usual advice is the opposite: let a crawler fetch, so it can read the
# page's noindex, because a robots-blocked page can still be indexed URL-only.
# That trap needs an inbound link to fire, and /discovery has none — unlinked
# from every nav, absent from sitemap.xml. What it does have is the pricing
# model in its source. Refusing the fetch keeps that out of caches and
# answer-engine corpora; the noindex in the page covers anything that ignores
# this file.
#
# This is obscurity, not access control. Anyone holding the URL can still read
# the source. If that stops being acceptable the fix is server-side auth on
# the path, not another line in here.
